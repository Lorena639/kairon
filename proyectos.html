Proyectos

Lo que estamos construyendo

KAIRON es un proyecto académico de dos estudiantes de SMX. Aquí está cada pieza, con su estado real.

  1. 01
    Publicada

    Web corporativa

    La cara pública de KAIRON: portada, servicios, SOC de demostración, equipo y versión en catalán. Se puede instalar como app.

    Tiene escena 3D con Three.js y fallback 2D, animaciones ligadas al scroll, consola de alertas simulada y simulador de ataque. También funciona como PWA y respeta quien prefiere menos movimiento. Falta conectar el formulario.

    • HTML, CSS y JS
    • Three.js
    • GSAP
    • PWA
  2. 02
    Planificado · parte del TFG

    Laboratorio SOC

    Red virtual aislada con cortafuegos, servidor Linux, equipos Windows y una máquina atacante, para probar ataques con seguridad.

    Se montará en VirtualBox con Wazuh como SIEM. Servirá para lanzar dos ataques de prueba, fuerza bruta y un ejecutable simulado con persistencia, y comprobar que se generan alertas. Va aislado para no afectar a ninguna red real.

    • VirtualBox
    • Wazuh
    • pfSense
    • Linux y Windows
  3. 03
    Planificada · parte del TFG

    Herramienta forense

    Recoge procesos, conexiones, usuarios, inicios de sesión y persistencia, y genera un informe con hora UTC, número de caso y SHA-256 de cada prueba.

    Se usará en el equipo afectado y entregará un informe en JSON y Markdown. Cada prueba lleva su hash para poder demostrar que no se ha modificado. La hacen entre las dos partes del equipo: seguridad define qué recoger y programación lo construye.

    • Python
    • Cadena de custodia
    • SHA-256
  4. 04
    Objetivo: enero de 2027

    Demo de un ataque completo

    La prueba de que todo encaja: un ataque simulado, Wazuh lo detecta, la herramienta recoge las pruebas y sale el informe.

    Es el centro de la presentación. Se ensayará en enero y habrá un vídeo de reserva por si algo falla ese día.

    • Fuerza bruta
    • Phishing simulado
    • Informe
  5. 05
    Estudio terminado · sin prototipo

    KAIRON Data Chip

    Dar a cada dato una identidad propia: huella, clasificación, política de acceso e historial. Es una línea futura, fuera del alcance del TFG.

    El estudio separa lo viable hoy, lo experimental y lo imposible. El primer prototipo sería un agente para Windows que registra archivos, detecta copias a USB y guarda eventos firmados en un log verificable.

    • Estudio de viabilidad
    • Arquitectura
    • Plan por fases
  6. 06
    Primer producto elegido · en diseño

    KAIRON Agents

    Plataforma de agentes de IA de seguridad con permisos, autonomía configurable e historial auditable. Es el primer producto del plan de empresa; aún no hay prototipo.

    El plan empieza por un solo agente con permisos y registro de actividad, y luego añade un panel central para gestionarlos.

    • IA especializada
    • Permisos
    • Auditoría
    • Local y nube
